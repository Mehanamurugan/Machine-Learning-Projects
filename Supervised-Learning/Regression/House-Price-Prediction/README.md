# House Price Prediction

Machine Learning regression project to predict house prices based on features such as location, area, number of bedrooms, and amenities using multiple regression algorithms.

---

## Project Overview

This project focuses on predicting house prices using different Machine Learning regression models and comparing their performance using evaluation metrics.

The workflow includes:
- Data preprocessing
- Handling missing values
- Feature encoding
- Feature scaling
- Model training
- Model evaluation
- Visualization
- Feature importance analysis

---

## Algorithms Used

- Linear Regression
- Random Forest Regressor
- Support Vector Regressor (SVR)
- XGBoost Regressor
- LightGBM Regressor

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- LightGBM

---

## Workflow

1. Import Libraries
2. Load Dataset
3. Handle Missing Values
4. Encode Categorical Features
5. Split Features and Target
6. Train-Test Split
7. Feature Scaling
8. Train Multiple Regression Models
9. Evaluate Models
10. Compare Performance
11. Visualize Results
12. Identify Best Model

---

## Evaluation Metrics

- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Objective

The objective of this project is to build accurate regression models for predicting house prices and analyze the key factors influencing property pricing.
