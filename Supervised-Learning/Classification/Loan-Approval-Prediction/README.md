# Loan Approval Prediction

Machine Learning classification project to predict loan approval status based on applicant details such as income, education, loan amount, and credit history.

## Algorithms Used
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Naive Bayes
- Decision Tree
- Random Forest
- Gradient Boosting

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Workflow
1. Data Cleaning
2. Handling Missing Values
3. Label Encoding
4. Feature Scaling
5. Model Training
6. Model Evaluation

## Evaluation Metrics
- Accuracy Score
- Precision
- Recall
- F1 Score
- Confusion Matrix

## Objective
Build a classification model to assist financial institutions in predicting loan approval outcomes.
