# Customer Segmentation using Clustering Algorithms

Machine Learning clustering project to segment customers based on purchasing behavior using multiple clustering algorithms and PCA for dimensionality reduction.

---

## Project Overview

This project focuses on customer segmentation using unsupervised learning techniques. Different clustering algorithms were applied and compared to identify the best-performing clustering approach based on silhouette scores.

The project also includes:
- PCA for dimensionality reduction
- Cluster visualization
- Elbow Method analysis
- Dendrogram analysis
- Silhouette score comparison

---

## Algorithms Used

### Clustering Algorithms
- K-Means Clustering
- DBSCAN
- Agglomerative Clustering

### Dimensionality Reduction
- Principal Component Analysis (PCA)
